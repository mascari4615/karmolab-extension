# YouTube management panel

- Mode: Operate. Inherit the existing YouTube screen and extension controls.
- User-selected reference: YouTube's top-bar entry and right-side panel composition.
- Live reference: masthead height 56px, existing `#buttons` action group, dark theme on 2026-10-24.
- Follow YouTube's root dark attribute for the surface, text and action palette. Actual YouTube no longer exposes the legacy theme variables; set them locally on the panel and trigger, keeping the page unchanged.
- One top-bar KarmoLab button, one nonmodal panel below the masthead, separate translation, keyword and blocked-user groups without nested cards.
- A close button, Escape and outside click dismiss the panel. Retain unsaved keyword input across dismissal.
- Immediate reversible toggles. Keyword drafts have an explicit Save action. Persistent blocked users have individual Unblock actions and search.
- Prefer icons for familiar repeated actions, with localized accessible names, tooltips and visible focus. Keep setting labels, reasons, restore confirmation and error messages as text. Use native controls, 44px panel targets and 16px text inputs. Keep panel within narrow viewports.
- Extend the accepted panel with Shorts controls and a backup section. Scroll the blocked-user list independently so backup controls remain reachable.
- Show up to three compact icon toasts with blocked status, Undo and Dismiss. Dismiss after six seconds, pausing on hover, keyboard focus and pending undo. Keep later recovery in the panel.
- Download stored preferences. A selected restore file shows counts and merge semantics before an explicit restore action; preserve unsaved keyword drafts.
- Compact comments: timestamp gutter, a 20px profile image before the author, and body on the first line. Keep short comments at 28px with the native profile control; use a 44px hit target for coarse pointers. Body type at 15px/22px, author and date at 12px/22px. Use the strongest neutral for content, muted blue for the author, and secondary neutral for the date. Preserve native content folding. Reveal reactions on hover/focus; keep actions visible for coarse pointers.
- Place the native translation control in reserved space at the comment's trailing edge. Show short Original/Translate labels while retaining the full native accessible text and state. Avoid an extra row and preserve keyboard operation.
- Use a small pencil beside the date for edited comments, preserving the native date link and full accessible text. Keep the same date type and alignment for ordinary and edited comments.
- In compact mode, hide the repeated author handle from the content row. Keep the native profile control and its accessible label, and expose the handle as its tooltip. Start the body immediately after the profile image.
- At desktop widths, place native reply counts and collapse controls beside the comment. Group expanded replies with a single thin line and shallow indentation. Keep native nested reply loading; on narrow or coarse-pointer screens, leave reply controls in normal flow with larger targets.
- Home sizing uses requested columns, not a fixed pixel width. Share one radio-step control between the Home toolbar and management panel: 2 through 6 cards per row, plus native default. Keep the requested count on wider screens so cards grow proportionally; narrow windows may reduce columns for readability. Click, drag and keyboard selection preview immediately and serialize persistence with rollback to the last saved choice on failure.
- Where row-based reading flow is supported, backfill Home grid gaps around full-width shelves and align keyboard focus with visual rows. Otherwise keep source order and ordinary grid placement.
- Comment sliders preview on input and save on release. Text 12-20px and requested line height 18-32px with at least 4px extra over text size. Validate numeric backups and restore the saved view if persistence fails. Migrate legacy Home pixel settings to columns.
- Home card blocking uses an icon beside the existing More button, visible on hover/focus or always for coarse pointers. Keep its accessible label, confirmation and Undo; reserve icon space without adding a row.
- Keep Home-only channel hiding separate from blocking. Its eye-off action hides the channel locally on Home and attempts native Not interested feedback with the requested reason for the clicked video only. Report partial native flows honestly, never retry an ambiguous mutation, and keep an independent Show on Home list and backup data. Undoing local hiding does not undo submitted YouTube feedback.
- The profile image opens a small nonmodal menu with the handle, native channel link, and existing block confirmation/undo flow. Escape, outside click and navigation dismiss it. Keep channel links same-origin and validate the current comment identity before blocking.
- Keep the native expanded-comment collapse control near the viewport bottom; after collapsing an offscreen-start comment, return to its start and focus the native expand control.
- Compact timestamps use s/m/h/D/W/M/Y with the original native text retained for accessibility and a full tooltip. Keep edited state separate from abbreviation.
- Shorts comments need their own narrow-panel layout: a 32px date gutter, 20px avatar, body starting at 68px, and reply toggles in normal flow under the text. Reserve translation space only where a translation control exists. Do not reuse the wide-watch trailing action allocation in a 480px panel.
- Shorts comment width: default 640px, user range 320-960px with responsive limits. Keep a visible grip on the left edge. Arrow keys change 16px (Shift: 64px), Home and double-click reset, End maximizes, Escape cancels dragging. Preserve the requested width during window resizing; restore native panel width when comments close or another panel opens. Save on release, with rollback and an error tooltip on failure.
- Reply filtering conceals unreviewed content before paint, including descendant visibility overrides. Reveal only after both filters acknowledge the current content. Keep native pagination when any continuation remains. Replace a proven fully filtered group with a neutral status, reversible by settings and filter exceptions.
- Place preview volume alongside the Home column control in the same wrapping toolbar. Show the current percentage and a Follow video volume checkbox. Moving the slider selects a custom preview level; persist on release and roll back on save failure. Do not unmute previews or overwrite the site's stored video volume.
- Translation status uses a spinner while the native request is pending, a warning on timeout, and an original-language badge after completion. Keep SVG flags independent of Windows emoji rendering; use an ISO badge for known languages without a suitable flag. Unknown stays a globe. Preserve full language names and confidence source in accessible tooltips.
- Put the automatic-block exception list directly below keyword controls, sharing a searchable author list and icon action between the panel and popup. Resuming automatic blocking is reversible through the subsequent Undo toast.
