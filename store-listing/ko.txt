유튜브와 아카라이브를 내 방식으로 읽고, 자주 쓰는 사이트 도구를 한곳에서 관리하세요.

KarmoLab은 댓글 모양과 영상 배치, 보고 싶지 않은 콘텐츠, 사이트별 화면과 음량을 조절하는 브라우저 확장입니다. 확장 아이콘을 누르면 유튜브, 아카라이브, 사이트 도구가 탭으로 나뉜 설정창이 열립니다.

유튜브
- 댓글을 컴팩트하게 표시하고 글자 크기와 줄 높이를 조절합니다.
- 홈 화면의 한 줄 영상 수를 2~6개로 선택합니다.
- 키워드에 맞는 영상, 쇼츠, 댓글을 숨기고, 작성자와 채널을 차단하거나 해제합니다.
- 유튜브가 제공하는 한국어 번역 버튼을 자동으로 누릅니다. 직접 원문으로 바꾼 댓글은 유지합니다.
- 쇼츠의 게시 날짜와 오늘 본 쇼츠 수, 쇼츠 재시청 횟수와 시청 시간을 확인합니다.
- 설정과 차단 목록을 JSON으로 백업하고 합쳐 복원합니다.

아카라이브: 직접 켜서 사용하는 선택 기능
- 일반 차단과 개념글까지 숨기는 강한 차단을 선택합니다.
- 검색이나 여러 채널이 섞인 목록에서도 해당 글의 원래 채널을 차단합니다.
- 차단 직후 되돌리거나 관리 화면에서 작성자를 검색해 해제합니다.
- 지정 채널에서 확인한 글과 작성자의 공개 최근 글 이력을 기준으로 자동 차단합니다. 모든 과거 글을 조사하는 기능은 아닙니다.
- 팔로우 글 모아보기, 읽음, 스크랩 표시와 활동 정보를 제공합니다.
- 켜거나 끈 뒤 열린 아카라이브 탭은 새로고침해야 합니다.

사이트 도구
- 직접 허용한 사이트에 다크모드를 적용합니다.
- 사이트별 음량을 기억하고 최대 300%까지 조절합니다.
- Base64로 적힌 HTTP/HTTPS 웹 주소를 열 수 있는 링크로 표시합니다.

알아두세요
댓글 번역은 유튜브가 한국어 번역 버튼을 제공할 때만 동작합니다. 홈 추천 숨김은 누른 영상에 유튜브의 관심 없음 의견 전송을 시도하며, 로컬 숨김을 해제해도 이미 전송한 의견은 취소되지 않습니다.

100%를 넘는 음량 증폭은 적용한 탭의 오디오 캡처 권한을 사용합니다. 마이크와 영상은 캡처하지 않으며 오디오를 녹음하거나 업로드하지 않습니다.

설정, 차단 목록과 기능 사용 기록은 브라우저에 저장합니다. 별도 수집 서버로 전송하지 않습니다. 아카라이브의 공개 글, 프로필과 로그인된 스크랩 목록 조회에는 기존 사이트 세션을 사용합니다. 아카라이브와 사이트 도구는 직접 기능을 켜고 접근을 허용한 사이트에만 적용됩니다.
