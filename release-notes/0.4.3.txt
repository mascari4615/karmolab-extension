KarmoLab 0.4.3 adds optional Arca.live tools and combines settings into one extension popup with YouTube, Arca.live and site-tool tabs. The YouTube button opens this same popup. The toolbar popup width is corrected, and membership badges no longer add an empty line in compact YouTube comments.
Arca.live tools include two-level user blocking, original-post channel blocking in mixed feeds and search, immediate blocking and undo, automatic blocking based on encountered posts and public recent author history, follow feed, read markers, scrap markers and local insights. Lists and records stay in browser storage. Existing site sessions are used for site requests. The one-time local development migration has been removed; existing migrated data remains intact.
No new permission names or mandatory host access compared with 0.4.2. Arca.live access uses the existing optional host permission and is requested only when the user enables the feature in the popup. No analytics or user-list uploads. The store ZIP excludes the local reload receiver and development permissions.
Validation: 90 Node tests; native toolbar popup width verified; compact-comment badge layout checked in isolated Edge across 16 combinations. Live Arca.live interactions and the reported video's final comment viewport were not verified in this session.
