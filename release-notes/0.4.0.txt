KarmoLab 0.4.0 update for the existing Chrome and Edge listings.
YouTube: automatic Korean comment translation with a toggle; in-page settings panel; keyword filtering; channel blocking with undo and JSON backup/merge restore.
Compact comments: profile menu, adjustable text and line height, short relative dates with full-date tooltips, edited indicator, wider Shorts comment text and reply threads.
Home: shared 2-6-column controls with live preview, compact card actions, and an independent Home-only channel hiding list. Shorts: local daily unique videos, qualified visits and visible playback time. Paused, hidden, blocked and advertising playback excluded; loops do not create visits. No history upload.
Base64 HTTP/HTTPS link discovery on individually enabled sites. Optional site volume up to 300%; amplification requires explicit tab capture. No microphone recording or audio upload.
Review: test Home column changes and restore, comments/replies, blocking/undo, backup validation, and Shorts navigation. Recommendation feedback was verified in a local fixture; live feedback submission was excluded at the owner's request.
